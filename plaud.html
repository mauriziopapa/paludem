Autenticazione

Come ottenere il token:
1. Vai su web.plaud.ai e accedi
2. Apri DevTools (F12) → Application → Local Storage → web.plaud.ai
3. Copia il valore di tokenstr
Oppure: Network tab → copia l'header Authorization da qualsiasi richiesta a api.plaud.ai

Se ricevi errori CORS, usa un proxy. Lascia vuoto per chiamate dirette.

API Ufficiale (platform.plaud.ai):
Crea un'APP nella Developer Console per ottenere Client ID e Secret Key.
